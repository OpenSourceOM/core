1. Build and load an image (the default repository is a placeholder until you publish one):

   docker build -t ghcr.io/opensourceom/core:0.3.0 .

2. Install with required secrets:

   helm install om deploy/helm/opensourceom \
     --set api.secret='change-me' \
     --set postgres.password='change-me' \
     --set image.repository=ghcr.io/opensourceom/core \
     --set image.tag=0.3.0

3. Open the console via the ClusterIP service or `kubectl port-forward svc/om-opensourceom 8080:8080`.

Scheduled collectors reconcile into this release's Postgres with `om scan`. They stay off until credentials are set. `om scan demo` remains a one-shot command.
